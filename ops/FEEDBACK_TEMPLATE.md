# 実機フィードバック記入テンプレート（波シート）

タブレット/スマホ/PCで実機テストをしながら、このテンプレートをコピーしてメモに記入し、
そのまま Claude に貼り付けてください。貼り付けたら **`/wave-feedback`** と一言添えるだけで、
分類→修正→検証→コミットまで自動で進みます。

- 全部の欄を埋める必要はありません。**「起きたこと」だけでも処理できます**（不足分はAIが推定し、曖昧な点だけ質問します）。
- スクリーンショットがあれば一緒に貼ると特定が速くなります。
- 1件1ブロック。軽微なものは下の「1行形式」でまとめてOK。

## 1行形式（軽微なもの・要望のまとめ書き）

`[重大度] 場所: 症状 → 期待する動き` の形で1行ずつ。

例:
```
[軽微] 図鑑: 和歌カードのふりがなが小さい → 一回り大きく
[要望] 2話: 札を取ったときの効果音がほしい
[進行不能] 4話歌合: 判者の台詞の後に進まなくなる
```

---

## 重大度の目安

| 重大度 | 意味 | 処理順 |
|---|---|---|
| 進行不能 | 起動しない・先に進めない・操作が塞がる | 最優先。単独コミットで即修正 |
| 目立つ | 明らかにおかしい表示/音/挙動（進行は可能） | 2番目 |
| 軽微 | 気になるが実害の小さい表示ゆれ等 | 3番目・まとめて修正 |
| 要望 | 新しい演出・機能の追加 | 修正と分離して計画（大きいものは別ブランチ） |
