# 寝殿造り3D探訪

平安貴族の邸宅様式「寝殿造り」を、3D空間を歩きながら学べるブラウザ完結型の学習ゲームです。建物・建具・調度品・人物・怪異・和歌・年中行事を、自由散策、クイズ、物語、ミニゲームで体験できます。

現在の正本は GitHub `origin/main` です。作業前と公開前は必ず `git fetch origin` し、古いローカルHTMLを正本にしないでください。

## 現在の主な機能

- **3D寝殿造り探索**: 寝殿、対屋、渡殿、釣殿、築地、門、庭、池、季節植物を歩いて確認できます。
- **図鑑と名称札**: 建築、建具、調度品、人物、怪異、生き物、霊獣、和歌を項目別に記録します。
- **名称当てクイズ / タイムアタック**: 対象を探してクリック/タップし、ローカル順位を保存します。
- **貴族の一日**: 男性貴族・女性貴族の生活導線を短い体験モードとして学べます。
- **垣間見ミッション**: 東格子、北壁代、妻戸先の観察地点を使い、巡回や警戒を避けて進みます。
- **物の怪退治**: 破魔の矢/札、ガード、回避、御神酒、季節ボス、専用HUDを備えた戦闘モードです。
- **物語モード「御簾の向こうへ」**: 6章構成、選択肢、章別BGM、ミニゲーム連携、5種のED分岐、回想、手動記録を備えています。
- **章選択と記録**: 章メニュー、オートセーブ、3枠の手動セーブを備え、旧保存形式も安全に読み替えます。
- **ED分岐ゲージ**: 結末到達後に章メニューへ解放され、現/雅/蝕の予兆を可視化します。
- **香合わせ**: 恋愛進行とは独立した学習モードで、六種の薫物や香りの文化を解説付き問題で学べます。
- **恋愛/陰陽系の基盤**: 恋の母屋ハブ、恋愛内の香合わせ、牛車外出、30日イベント、陰陽寮の占い補正が入っています。
- **車宿と牛車運び**: 散策中に車宿/牛車を調べると、車寄まで牛車を運ぶミニゲームを開始できます。
- **太極六壬式盤の占い**: 散策中に式盤を調べ、西暦/干支/十二天将/五行を使った占断を表示できます。
- **絵巻断片収集**: 邸内の断片を集め、西の対の継ぎ台で導線を確認できます。
- **屋敷の生活**: 主人、北の方、子女、家司、乳母、命婦、下女、随身、舎人、下男などを配置。7役は朝昼夕夜の日課で行動し、会話の聞き耳や使者・来客・牛車の到着が発生します。
- **軽量描画モード**: 低性能端末向けに画質、影、ブルーム、季節粒子、フレームレートを一括で抑え、解除時は元の設定へ戻します。
- **季節・時間・天候演出**: 春夏秋冬、昼/夕/夜/夜明け、雨、桜吹雪、灯籠流し、月映りなどが連動します。
- **音響**: 環境音、足音、管弦、退治SE、ボスBGM、物語BGMを使用し、欠損時は合成音へフォールバックします。

詳細な実装済み/ブランチ状況は [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) を参照してください。

## 起動方法

1. `寝殿造り3D探訪_統合版.html` をブラウザで開きます。
2. 音を鳴らす場合は、同じ階層に `sounds/` フォルダを置いてください。
3. GitHub Pages では `index.html` から本体HTMLへ遷移します。

## 操作

| 環境 | 移動 | 視点 | 調べる |
|---|---|---|---|
| PC | WASD / 矢印キー、Shiftで早歩き | ドラッグ | クリック |
| タブレット/スマホ | 左下ジョイスティック | ドラッグ | タップ / 右下「調べる」 |

上部バーから、モード、季節、時刻、名称札、図鑑、画質、音量を切り替えられます。物語/退治/恋愛など一部モードでは専用HUDが優先されます。

## 開発と検証

初回のみ:

```bash
npm install
```

よく使う検証:

```bash
npm run build:story:check
npm run verify:html
npm run verify:story
npm run verify:routes
npm run smoke
npm run verify:public
npm test
```

`npm test` は、物語ビルド同期、HTML静的検証、ストーリー整合、EDルート、Playwrightスモークをまとめて確認します。公開後のGitHub Pages確認は `npm run verify:public` で行います。

## 保守ルール

- Three.js は r128 前提です。`outputEncoding` / `sRGBEncoding` / `texture.encoding` を維持し、新しい `colorSpace` API は使いません。
- 単一HTML方針を維持します。分割や外部CDN追加は、配布性とオフライン性への影響を確認してから行ってください。
- `src/app/` と `story/` に正本がある埋め込み範囲はHTMLを直接編集せず、`npm run build:app`、続けて `npm run build:story` の順に再生成してください。2つの書き込みビルドを並列実行しないでください。
- `ITEMS`, `register()`, `pick()`, `enterMode()`, `animate()`, CSS HUD、音声初期化は衝突しやすい領域です。
- Claude/Codex 並行作業時は、必ずブランチで作業し、`origin/main` を取り込んでから push してください。
