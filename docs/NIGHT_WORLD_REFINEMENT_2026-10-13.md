# 夜・植栽・人物・鎌倉の造形改善

2026-10-13。公開main `bebc306`（徒然草第七段と孫の表情修正を含む）からの追加改修。既存44項目の公開とは別の変更で、第2ストーリー・追加マップ・新ボスの製品実装は含まない。

## 今回の体験

- 朝・昼・夕・夜の切替でPointLight数を固定。高画質4灯、中画質3灯、省電力/低画質2灯の共有枠へ、近くの有効な灯りを割り当てる。未使用枠は強度0で描画数を保ち、時刻ごとのshader再コンパイルを抑える。炎・灯籠の模型と発光色は保持する。
- 動く灯り、後から追加された灯り、消灯/再点灯、非表示の親、モード退出時の解放に対応。図鑑単体/比較では対象模型の灯だけを使う。徒然草第七段では元の照明制御へ戻し、退出後に通常枠へ復帰する。
- 楓・椿の葉を、枝先から小枝・葉柄へ連なる単葉へ変更。風でも基部を離さない。楓は冬に落葉、椿は常緑で既存の花を保持する。図鑑の冬椿も対象の15輪を描画し、共有45輪の元配置を復元する。
- 人物の頬〜顎・首・鬢を共有形状で整え、鴛鴦/鶴の嘴と翼、牛の顔と脚に追従する蹄、環境怪異の近景を補う。河童の肩〜腕〜手、提灯の口〜舌の隙間も補正する。
- 鎌倉を21領域で点検。門の中央障害物と浮いた戸/金物、仏像の床への埋没、建物の支持/階段、井戸の滑車〜縄〜桶、馬の首/顔/馬具、建具・武具・田と堀の配置を修正。平安側のまま残っていた歩行障害物を鎌倉専用配置へ変更する。
- 添付の扇は既存の拾得探索用「落とし扇」。紙の折り・骨・要・持手・結び紐を作り、近くのボタンからその調査へ直接進める。
- 図鑑8項目の本文を模型の形と用途へ合わせ、貴族/武士の住居や信仰を一律に二分する説明を修正する。

## 徒然草の再現モードから参考にしたこと

顔・首・衣の接続、枝から葉までの連続、木/布/肌/金属の材質差、近景と遠景の資源共有を既存世界へ移した。全人物へ重いSDFを追加する方式ではない。`saigen-tsurezure.js` と `tsurezure-*.js` の元作品はそのまま維持した。回帰検査ではshaderエラーも除外せず検出する。

## 性能の読み方

同一PCのChrome、1280×800、固定seed、適応画質停止、bloomなし、手動時刻、各時刻42フレーム（最初12の最大値、残り30の中央値）をGPU完了まで計測。比較元は今回取得した最新Claude版。省電力でもFPS上限によるフレームのスキップを避けて実描画する。

初回夜切替の旧実装は高画質で8→14灯となり43個のshaderを追加、省電力も38個追加した。変更後は4灯/2灯のまま、高画質で1個、省電力で0個の追加。手元の計測では初回の大きな停止を抑えられた。正確な値と全16条件は [計測記録](metrics/NIGHT_WORLD_REFINEMENT_2026-10-13.json) を参照する。

| 初回の夜切替 | 変更前の最大フレーム | 変更後の最大フレーム | 追加shader数（前→後） |
| --- | --- | --- | --- |
| 高画質 | 10,091.7ms | 58.0ms | 43→1 |
| 省電力 | 7,987.5ms | 12.0ms | 38→0 |

起動後に初めて描画する朝は変更後も約5.9秒、最初の省電力切替は約3.2秒の生成が残る。上の値はその測定経路の初回夜を示し、端末一般の応答時間を保証する値ではない。

初回起動と画質変更そのもののshader生成、モデル/音源の初回ロードは残る。繰返し切替後の通常フレームは旧版でも速く、すべての場面のFPSが大幅に増えるという結果ではない。10視点の比較も同記録へ保存する。描画計測はゲーム全体の入力/音処理時間を含まない。

描画比較は、検査用HTTP応答だけでThree r128のUUID乱数をゲーム乱数から分離し、変更前に記録したカメラ位置/向き/FOVを変更後にも使用する。元の製品HTML/Threeライブラリは書き換えない。初期比較はUUID生成の増減が鳥と灯籠の移動パラメータを変え、可動模型に合わせたカメラも動いたため、描画callsの厳密比較から除外した。採用する記録は `refinement-matched-before/after`。

iPhone/iPad実機の性能は未測定。PCのタッチ/狭幅検査を実機結果として扱わない。実機では初回起動、初回夜切替、灯籠/室内、15分の連続散策、発熱後の省電力、モード往復を確認する。

## 検査と再現

`npm test` は既存モード・物語/保存・戦闘・時刻/画質・GPU資源の往復検査、徒然草第七段13場、新しい専用検査を順番に実行する。生成は `npm run build:app` → `npm run build:story` の順。

専用検査は `npm run test:refinement`。葉の接合/季節/LOD/花の単体と比較/例外復元、光源数と可視状態/所属/例外復元、人物の外向き法線、脚支点、怪異の接合、鎌倉28判定を含む。低画質・省電力を戻しても距離境界の通常LOD履歴を失わないことも検査する。

画像の再取得は `VISUAL_SCENES` に `tree,tree-autumn,camellia-winter,hime,duck-front,crane-front,ox,kappa,chochin,yukionna,night` を指定し `node scripts/benchmark-visual.js review`。鎌倉の9視点は専用検査で保存する。画像・一時HTMLは `artifacts/` の検査別フォルダに保存し、公開物へ含めない。

2026-10-13の `npm test` 一式成功。徒然草第七段13場、葉/花の反復と例外復元、鎌倉28判定を確認。4回ウォームアップ後の24回のモード往復で、scene登録数/模型資源数の増加と動的GPU資源の残存は0。初回の画面表示に伴う既存world/cacheのGPU登録は別に識別しており、GPU総量が一切変わらないという判定ではない。
