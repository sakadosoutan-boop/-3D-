# ビジュアル改善の残件

2026-10-06 時点の画面・実装レビュー。優先度は見た目への影響と散策中の目立ちやすさで並べた。新しいスクリーンショットや端末計測で更新する。

| 優先 | 対象 | 残る問題と完了の目安 |
| --- | --- | --- |
| 高 | 松・広葉樹の輪郭 | 松の葉叢が同じ厚さの円盤を重ねた形に見える。広葉樹も丸い塊の反復が残る。幹から枝先まで自然に連なり、近景でも樹種を見分けられる輪郭にする。 |
| 高 | 冬の植栽・積雪 | 樹冠の雪は上面の色分けだけで、枝・根元・庭地面との積もり方に差がある。屋根や庭石を含め、上向きの面に雪が載る規則を揃える。 |
| 高 | 池の岸と水 | 水際の直線的な境目、均一な青、岩の配置の規則性が残る。浅瀬・湿った砂・岸石を一続きに見せる。 |
| 高 | 建物の屋根・軒 | 遠景で屋根の縞と形が反復し、近景では軒端と接合部が単純に見える。棟・軒・隅の陰影と材の違いを強める。 |
| 中 | 庭全体の密度 | 南庭の飛石まわりは改善したが、広い空白と植栽の反復が残る。牛車の走路と歩行線を保ちながら、場所ごとに異なる下草・岩組を配置する。 |
| 中 | 人物と衣装 | 顔・髪・手、衣装の重なりや裾の接地が建物より簡略化されて見える。近景の人物から造形と材質を揃える。 |
| 中 | 室内 | 大きな白壁と均一な天井・床が目立つ。襖・御簾・調度との奥行き、間接光、接地影を整える。 |
| 中 | 夜・夕景 | 夜の建物は暗部に埋もれ、灯りの届き方が一様。夕景では空と建物の色のつながりが弱い。時刻別に見える情報量を調整する。 |
| 中 | 橋と牛車 | 朱塗りの彩度、橋脚の接地、牛車の車輪・軛・荷の質感を再点検する。移動中の揺れやカメラから見た印象も確認する。 |
| 中 | 季節の花・動物 | 椿以外にも花・鳥・蝶などで板状・球状に見える造形がある。間近で確認し、形と配置を樹木や地形に馴染ませる。 |
| 低 | 空と遠景 | 雲帯は修正したが、地平線付近の単調さと遠景の平板さが残る。霧・空色・遠景の明度を時間帯ごとに調整する。 |
| 継続 | 描画負荷 | 各追加物をインスタンス化し、高画質・省電力の両方で描画回数、三角形数、GPU待ち時間、季節切替時のメモリを確認する。 |

今回対処した不具合: 椿の花が樹冠から離れた桃色の球になること、松の枝が葉叢の手前で途切れること、冬の松が全面灰色の塊になること、松の先端だけ白い円錐になること。
