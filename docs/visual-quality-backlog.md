# ビジュアル改善の残件と対応状況

2026-10-06 更新。元の12項目すべてに改修を実施。対象ブランチは `codex/complete-visual-backlog`。描画負荷は継続的に計測する項目であり、全端末での完了を意味しない。

| 元の対象 | 今回の対応 | 確認方法 |
| --- | --- | --- |
| 松・広葉樹の輪郭 | 松の同寸の三段円盤を不均一な葉叢と針葉に変更。広葉樹の枝先・葉叢の配置を分散。松の幹と枝を材質別に結合。 | 夏・冬の近景、枝と葉の接続、低画質からの復元 |
| 冬の植栽・積雪 | 上向きの法線に沿って枝・岩・葉へ雪を載せる。松の下側は緑を保持。落葉樹の葉を減らし、根元へ縁をぼかした積雪を追加。白砂の雪に風と踏み道の濃淡。 | 岩の上面と垂直面のピクセル比較、四季往復、屋根の既存積雪検査 |
| 池の岸と水 | 外周を44から160点へ細分化し、内向きの揺らぎを追加。浅瀬を拡幅・変化させ、水面に場所ごとの青緑の濃淡。岸石・小石の間隔を崩す。 | 近景、重なる水面の色一致、波の描画・省電力停止 |
| 建物の屋根・軒 | 屋根の曲率に追従する隅棟の材を512区間、1バッチで追加。上面と端の材・陰影を分離。 | 屋根形状の閉じた面、上限高さ、雪、近景、省電力切替 |
| 庭全体の密度 | 場所別の下草243株、岩28個、苔を一括配置。中央白砂、橋の出入口、牛車の走路を避ける。 | 全配置の通行線・有限値・カリング範囲検査 |
| 人物と衣装 | 顎を絞った顔、裾の襞と下側の扁平化、絹と髪の反射を調整。顔・指・袖口を材質別に結合し、小部品の影を抑制。 | 室内近景、人物・物語を含むスモーク、描画回数 |
| 室内 | 漆喰に暖色と足元の陰影を追加。座位人物の接地影と、点火した灯台だけに床への暖色の広がり。 | 点火・消火・昼夜の連動、室内近景 |
| 夜・夕景 | 空色の反射光、環境光、月光、露出を調整。既存の灯りを維持しながら建物の暗部を読み取りやすくする。 | 夜景、時刻切替、月映り・炎の既存検査 |
| 橋と牛車 | 橋の朱を落ち着かせ、粗さを調整。牛車の車輪に追従する接地影、車輪から独立した客室の上下動と左右の揺れ。 | 地面に残る車軸、停止時復元、配送・タッチ・追従カメラ検査 |
| 季節の花・動物 | 鴛鴦の銀杏羽を三角板から曲面にし、鶴の首・尾羽・指、飛ぶ小鳥の羽の輪郭を変更。冬の根元を植栽へ馴染ませる。既存の椿・季節花の造形も維持。 | 季節表示、鳥の近景、花と橋のピック検査 |
| 空と遠景 | 敷地の外側に異なる輪郭の遠景を三層追加。朝・昼・夕・夜に色と霞を切り替える。 | 俯瞰・庭の近景、時刻切替、省電力非表示 |
| 描画負荷 | 追加物の一括描画、人物・松の結合、省電力時の装飾非表示。四季×4時刻を巡回してジオメトリ・テクスチャの再利用を検査。 | `npm test`、高画質／省電力の8視点比較。物理端末のGPU計測は継続 |

詳細な計測と検査結果は [今回の改修記録](metrics/VISUAL_BACKLOG_2026-10-06.md)、次の改善候補は [追加改善案](game-improvement-opportunities.md) を参照。

## 改修前の問題と完了の目安（履歴）

| 優先 | 対象 | 残る問題と完了の目安 |
| --- | --- | --- |
| 高 | 松・広葉樹の輪郭 | 松の葉叢が同じ厚さの円盤を重ねた形に見える。広葉樹も丸い塊の反復が残る。幹から枝先まで自然に連なり、近景でも樹種を見分けられる輪郭にする。 |
| 高 | 冬の植栽・積雪 | 樹冠の雪は上面の色分けだけで、枝・根元・庭地面との積もり方に差がある。屋根や庭石を含め、上向きの面に雪が載る規則を揃える。 |
| 高 | 池の岸と水 | 水際の直線的な境目、均一な青、岩の配置の規則性が残る。浅瀬・湿った砂・岸石を一続きに見せる。 |
| 高 | 建物の屋根・軒 | 遠景で屋根の縞と形が反復し、近景では軒端と接合部が単純に見える。棟・軒・隅の陰影と材の違いを強める。 |
| 中 | 庭全体の密度 | 南庭の飛石まわりは改善したが、広い空白と植栽の反復が残る。牛車の走路と歩行線を保ちながら、場所ごとに異なる下草・岩組を配置する。 |
| 中 | 人物と衣装 | 顔・髪・手、衣装の重なりや裾の接地が建物より簡略化されて見える。近景の人物から造形と材質を揃える。 |
| 中 | 室内 | 大きな白壁と均一な天井・床が目立つ。襖・御簾・調度との奥行き、間接光、接地影を整える。 |
| 中 | 夜・夕景 | 夜の建物は暗部に埋もれ、灯りの届き方が一様。夕景では空と建物の色のつながりが弱い。時刻別に見える情報量を調整する。 |
| 中 | 橋と牛車 | 朱塗りの彩度、橋脚の接地、牛車の車輪・軛・荷の質感を再点検する。移動中の揺れやカメラから見た印象も確認する。 |
| 中 | 季節の花・動物 | 椿以外にも花・鳥・蝶などで板状・球状に見える造形がある。間近で確認し、形と配置を樹木や地形に馴染ませる。 |
| 低 | 空と遠景 | 雲帯は修正したが、地平線付近の単調さと遠景の平板さが残る。霧・空色・遠景の明度を時間帯ごとに調整する。 |
| 継続 | 描画負荷 | 各追加物をインスタンス化し、高画質・省電力の両方で描画回数、三角形数、GPU待ち時間、季節切替時のメモリを確認する。 |

今回対処した不具合: 椿の花が樹冠から離れた桃色の球になること、松の枝が葉叢の手前で途切れること、冬の松が全面灰色の塊になること、松の先端だけ白い円錐になること。
