# 追加改善案 — 2026-10-06

今回の12項目への対応後に、さらに質を上げられる候補。既存の図鑑検索、クイズ復習、キー変更、色覚サポート、オンライン順位、セーブ、軽量描画は実装済みなので、新規機能として重複提案しない。

## ビジュアル

| 優先 | 改善案 | 期待できる変化・完了の目安 |
| --- | --- | --- |
| 高 | 人物の表情と手元の所作 | 会話時の目線、まばたき、扇や巻物を持つ指、声のない相槌。既存の座位や物語演出を維持して近景の人物を自然にする。 |
| 高 | 樹種ごとの葉・枝の形 | 松針、楓の掌状葉、椿の艶葉をさらに区別。現在の葉叢を減らしても樹冠が痩せ過ぎず、スマホで同じ樹種と分かる形にする。 |
| 高 | 室内の採光と建具の連動 | 御簾・半蔀の開閉に応じて、畳に差す光と壁の陰を変える。照明を増やす前に既存の光と事前計算を活用する。 |
| 中 | 浅瀬と水中の見え方 | 鯉の深さ、岸の濡れ、底石の透け方、動物や灯籠の局所的な波を揃える。水面が重なる境界を再発させない。 |
| 中 | 季節の移り変わり | 雪の厚み・融け残り、紅葉の色付き、花の咲き方を段階化。日陰・屋根下・通路で堆積量を変える。 |
| 中 | 風の統一 | 草、竹、藤、衣の裾、水面を同じ風向きで動かす。視差効果を減らす設定と省電力で停止・簡略化する。 |
| 中 | 近景の材質の尺度 | 漆の反射、木の継ぎ目、檜皮の重なり、金具の擦れを同じ実寸の尺度で揃える。画面全体にノイズを増やさず差を出す。 |
| 低 | 撮影の構図補助 | 既存撮影モードへ画角・被写体への注目・撮影位置の保存を加え、端末ごとのスクリーンショットも比較しやすくする。 |
