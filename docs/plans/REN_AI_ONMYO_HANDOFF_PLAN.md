# 恋愛/陰陽系 実装状況と残タスク

最終更新: 2026-07-08
基準: `origin/main` = `69a5c68`

この文書は、旧「恋愛シミュレーション・陰陽寮占いモード 引継ぎ計画書」を現行main向けに整理した正本です。古い実装前手順ではなく、現在入っている機能と次に残す作業だけを記録します。

## 実装済み

- タイトル/モード導線に恋愛系モードを追加。
- 恋文ショート体験:
  - 噂、牛車演出、垣間見、和歌カード選択、文の仲介、返歌、結果表示。
  - 返歌リビール、文/牛車/香の軽演出、結果ランク。
- 恋愛シミュレーション:
  - 30日制、対象選択、恋の母屋ハブ。
  - 日付、季節、行動、パラメータ、好感度、途中保存。
  - 香合わせ、牛車外出、年中行事/朝イベント、結末評価。
- 陰陽/占い:
  - 太極六壬式盤 `onmyo_shikiban` の3Dモデル、図鑑、札。
  - 西暦/干支/十二天将/五行/天盤回転/占断結果パネル。
  - 散策中の占い通知と、恋愛/外出への軽い補正。
- 車宿/牛車運び:
  - 車宿 `kurumayadori`、牛車、運搬ミニゲーム、HUD。
  - 退治/物語/恋愛/歌合/再現では邪魔にならない表示制御。
- 検証:
  - `npm test` の Playwright smoke で、車宿、牛車運び、太極六壬式盤の起動と基本動作を確認。

## まだ弱いところ

- 恋愛シミュレーションの各対象差が薄い。対象別の好み、嫌いな行動、固有イベント、固有EDを増やす余地がある。
- 占い結果が「雰囲気と軽い補正」に留まり、日付選択、牛車、文、訪問、怪異調査へ十分に効いていない。
- 牛車運びは単体ミニゲームとして動くが、恋愛/貴族の一日/物語第2話の必然的導線にはまだ弱い。
- 装束コーデ、贈り物、文の配達、忍び訪問、怪異調査は未完成または簡略表現。
- 30日モードの終盤に、積み上げた行動が物語的なクライマックスへ収束する演出が不足している。
- セーブデータ `shinden3d-renai-save-v1` のマイグレーション/破損復旧手順が未整備。
- 教材利用時に恋愛要素を控えめにする「教材モード」切替が未実装。

## 次に実装する順番

1. **占い結果の実効化**
   - 吉方/凶方を牛車外出、文の成功率、訪問イベント、怪異イベントへ反映する。
   - UIに「今日の吉凶がどの行動へ効くか」を1行で出す。

2. **牛車導線の統合**
   - 牛車運びを恋愛シミュレーションの外出準備や貴族の一日へ接続する。
   - 運搬結果を評判/財力/好感度へ小さく反映する。

3. **対象差の強化**
   - 対象ごとに季節、香、和歌傾向、嫌いな行動を明確化。
   - 返歌とED文を対象別に増やす。

4. **文の配達/仲介者**
   - 女房、侍従、門番など仲介者選択を入れる。
   - 成功率、評判リスク、慎みへの影響を分ける。

5. **装束/贈り物/怪異調査**
   - まず2Dカード型の軽量ミニイベントとして追加。
   - 3D着せ替えや大型戦闘化は後回し。

6. **保存と教材モード**
   - `shinden3d-renai-save-v1` のスキーマ文書化。
   - 破損時リセット、旧データ移行、教材モードでの恋愛表現抑制を実装。

## 編集時の注意

- `APP.renai`, `enterMode("renaiShort"|"renaiSim")`, `renderRenaiStep`, `startRenaiSim`, `RENAI_SIM_SAVE_KEY`, `openOnmyoDivinationPanel`, `executeOnmyoDivination` 周辺は衝突しやすい。
- 通常散策時の毎フレーム負荷を増やさない。恋愛/占い中だけ判定する。
- `npm test` を必ず通す。牛車/式盤を触った場合は Playwright smoke の該当項目も確認する。
