# 第2ストーリーと新ボス — 弓馬の館、帰りの文

2026-10-13。ユーザーの希望により推奨舞台を鎌倉の武家屋敷へ変更した。企画のみで、新章・新マップ・合戦・新ボスはまだ製品実装しない。

第1作の帰還と人物の成長を維持する。既存1〜6章・ED1〜5と旧セーブに新作の状態を混入させない。旧「巡り歌合」は平安の別案として残す。

## 推奨する体験

栞と蓮が読んだ書付から、架空の東国の館へ物語が開く。年代は既存鎌倉マップの13世紀前半を基準とし、実在の合戦の再現とは扱わない。蓮が再び昏睡したという導入にはしない。

館で人の仕事と施設の役割を知り、使いとして境を渡り、迫る争いの中で「何を、誰に、どう伝えるか」を選ぶ。生活・探索・文の読み・武芸・合戦を同じ筋の中でつなぐ。武士の暮らしを戦闘だけで表さない。

| 候補 | 中心となる体験 | 必要な舞台 |
|---|---|---|
| **弓馬の館、帰りの文（推奨）** | 館の暮らし、伝令、門の防衛、帰還と報告 | 既存館＋小さな河原・山道1マップ |
| 絵巻の合戦を歩く | 『平家物語』等の本文と描写の差を体験 | 実在合戦の地形・時系列・装備と底本の検証が大きい。別の再現モード候補 |
| 巡り歌合・返す判詞 | 歌と景物を照合し、判詞を訂正する | 平安の別案。鎌倉編へ無理に混ぜない |

## 章と人物

館主の若い一族、留守を預かる人物、郎党、厩の世話役、隣の里の使いが主要人物。名・家系・争いは創作。既存モデルの衣・役割差を利用し、特定の史実人物の顔とは扱わない。栞は現実側の入口と出口にいる。

| 章（目安） | 目的 | 実際に遊ぶこと |
|---|---|---|
| 一・館に着く（8分） | 主殿・侍所・厩・台所で、館を支える人に会う | 仕事を一つ手伝い、用具と施設の関係を記録。調査順で会話が変わる |
| 二・届いた二通（10分） | 同じ出来事を違って伝える文が届く | 送り手・宛先・日時・伝言の許可を照合。不足した情報を聞く |
| 三・境を渡る（12分） | 河原・渡し・山道を経て相手に会う | 通れる道を観察し、荷と伝言を運ぶ。武芸の稽古で学んだ操作を使う |
| 四・門を守る夜（12分） | 館の外で小規模な争いが起こる | 合図・門・退路を使い、守備と連絡を行う。誰へ助けを求めるか選ぶ |
| 五・帰りの文（8分） | 損失・誤解・残った約束を整理する | 見た事実と推測を分け、相手の返事を持ち帰る。選択履歴を結末に残す |

想定45〜55分。結末は、相互に根拠を確認して争いを収める、退路と人を守り不確かな点を残す、命令だけを守り返事を失う、調べる機会を放棄する、の4方向。討伐数だけで最高EDにしない。戦闘で失敗しても合流や退却後の報告へ進み、調査した証拠を失わない。

## 新マップと合戦

生活と初めの二章は既存館で成立する。合戦全体を同じ庭へ押し込まず、三章以降に**河原・渡し・短い山道をまとめた小マップを一つ**追加する。専用の大合戦マップは初回の必須条件にしない。

| 舞台 | 初回の範囲 | 制作・検証する要素 |
|---|---|---|
| 鎌倉の館 | 既存マップを磨いて利用 | 建具、床・階段、門の開口、厩・井戸・用具、人物、歩行判定 |
| 河原と渡し | 小規模な独立マップ | 水際、橋または渡し、分岐する道、地形・足場、往復時の保存 |
| 山道と館外の争い | 小マップ内の区画 | 見張り、合図、限定した射線、退路、門前との連絡 |
| 実在の大合戦 | 将来の再現モード | 底本、地形・時系列・軍勢の解釈、群集表現と性能予算 |

現在の時代移動はURL再読込を使う。新作の前に、舞台の生成・表示・所有資源の解放・歩行判定を分けるマップ管理を作る。全マップを常駐させず、館と河原で生成・解放・保存再開・カメラ・音・光の復元を実証する。

合戦の初期試作は門1か所、近くで動く人物4〜6人、射手2〜4人、共有形状で表す遠い軍勢を目安にする。これは測定前の設計値。遠い人物全員を個別AIで動かさない。射線を読む、地形で退避する、合図を送る、仲間と合流する、門と退路を保つ操作を作る。命中数は補助評価で、届けた情報も結末に影響する。説明文だけで戦闘を済ませない。

時間制限を緩めた操作を選べるようにし、スマホの退避幅とボタンを確保する。飛び道具・煙・光・遠景人物には上限を持つ共有プールを使う。夜の門前とiPhone/iPadの15分実測で性能を検証する。

## 「あだし野」再現モードから採る品質基準

公開main `bebc306` の `saigen-tsurezure.js` と `tsurezure-*.js` を参考にする。元の再現モードは維持し、設計を再利用する。

- 顔・首・肩・衣がつながる形。肌・木・布・金属で粗さと色を分ける。
- 幹→枝→葉柄→葉、支点→握り→手、礎石→柱→梁→屋根の接合。揺れや開閉でもつながること。
- 一場の中で場所が分かる引き、用具を見る寄り、人物の反応を組み合わせる。自由操作へ戻れるカメラを作る。
- 手掛かりの接写位置を用意し、文章と実際の形を対応させる。場面の光・音・霧は退出時に復元する。
- 接写用の高密度形状を全人物へ常時使わず、共有形状・近景の細部・遠景の簡略形を使い分ける。

## 新ボス候補

名・姿・由来は創作であり、史実の鎌倉伝承とは説明しない。人間同士の争いを「悪い人が怪異だった」で片付けず、退治は任意の寄り道として独立させる。

| 候補 | 読める予兆と攻略 | 配置・制作量 |
|---|---|---|
| **門を閉じる影** | 片側へ伸びる影を読み、予告された蝶番・閂へ回り、郎党の合図で札を置く | 既存門を使う。建具と判定の一致を先に試作 |
| **返らずの文** | 文の送り手・受け手・許可を照合して届ける | 文学ボス案を館と使いの経路へ改定。初期候補 |
| **渡しの水影** | 逆向きの波紋が偽の足場を示す。安全な経路を作る | 「逆流の水影」を小マップへ。水際判定の検証が必要 |
| **名落ちの馬具** | 馬影の轍から退避し、落ちた鞍・鐙・轡の対応を戻す | 牛車案を武家の教材へ。馬と馬具の品質が採用条件 |
| **綴じ目の境** | 館と河原が書付の頁のように並ぶ。相反する証言を区別して返す | 初回から外し、舞台切替の完成後に再検討 |

初期候補は「返らずの文」と「門を閉じる影」。縦切り試作に必要なものだけを作り、5体を同時追加しない。旧「判詞の影」は平安の歌合案で維持する。

## 考証と実装順

建築・道具は発掘資料、絵巻、現存品を参照する。舞台全体を特定の館の精密復元とはしない。未確認の会話・人物・使い・夜襲・怪異は創作。

- [鎌倉市・発掘調査速報展「水と暮らす中世」](https://www.city.kamakura.kanagawa.jp/rekibun/documents/handout-2018-2.pdf)：館の遺構、井戸・排水・生活用具の参照。上部構造すべての確定資料ではない。
- [文化庁・北条氏常盤亭跡](https://online.bunka.go.jp/heritages/detail/190532)：建物跡、柱穴、溝、井戸等を参照し、解明に残る課題を踏まえる。
- [奈良国立博物館・阿弥陀如来坐像1112-0](https://www.narahaku.go.jp/collection/p-1112-0.html)：平安12世紀の像。定印・衣・蓮華座、浄土と密教の接続を参照し、貴族と武士の宗教を二分しない。
- [鎌倉マップ考証計画](KAMAKURA_BUKE_YASHIKI_PLAN.md)：絵巻の年代差を確認し、後期の描写を前期の事実として断定しない。

実装順は、①館の品質と歩行を整える、②館だけで第1章と伝令を10分遊べる試作、③河原と所有資源管理、④門1か所の防衛、⑤全5章・4結末と任意の怪異。舞台20往復で継続的な資源増加がなく、保存再開・失敗継続・低画質・縦画面・旧EDの回帰を確認する。引用と年代を照合後、正式モードへ昇格する。
