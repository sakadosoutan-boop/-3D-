# 鎌倉武家屋敷マップ 時代考証・設計正本

最終更新: 2026-07-13 ／ 状態: 考証・設計（実装はOpus委譲）
背景: 生徒要望「鎌倉時代版で遊びたい」。将来目標「平家物語の再現」への第一歩として、寝殿造エンジンを再利用した**鎌倉時代の武家の館（方形館）**マップを追加する。

---

## 1. 時代設定と考証方針

**設定: 鎌倉前期（13世紀前半・承久の乱の前後）、東国御家人の館。**
平家物語が語る治承・寿永の乱（1180–85）を戦った坂東武者の子の世代が住む館であり、平家物語が「語り物」として形を成していく、まさにその時代。平家物語再現（§7）の東国側の舞台としてそのまま使える。

### 考証上の最重要注意（教材としての誠実さ）

> **「武家造」という独立様式は、現在の建築史学では否定されている。**
> 鎌倉武士の住まいは寝殿造と別系統の様式ではなく、**寝殿造を簡略化した主殿中心の構え**に、武士の生業（武芸・馬・防御）に必要な実用施設を加えたもの、というのが通説（のちの主殿造→書院造へつながる系譜）。ゲーム内の解説でも「武家造」という語を様式名として使わず、「寝殿造の簡略形＋武士の実用施設」と説明すること。**この学説状況自体が「教科書の記述は更新される」ことを学ぶ教材になる。**

### 一次典拠（実装・解説の根拠として引く絵巻・遺構）

| 典拠 | 年代 | 本マップが借りる描写 |
|---|---|---|
| 『一遍聖絵』（一遍上人絵伝） | 1299 | 筑前の武士の館：板塀・門・主屋・**中門廊の先の厩**・庭の構成 |
| 『男衾三郎絵詞』 | 13世紀末 | 武蔵の武士の館：**「館の四方に矢倉をかき」**（矢倉＝物見・矢の備え）、**馬庭の的**（的場）、侍所、厩、質実な暮らしと武芸稽古 |
| 『蒙古襲来絵詞』（竹崎季長） | 1293頃 | 武具・馬装・直垂姿の御家人風俗 |
| 方形館遺構（各地の「堀ノ内」「土居」地名、発掘例） | 鎌倉期 | **一辺50〜100mの方形を堀と土塁で囲む**という敷地の基本形 |

## 2. 館の構成要素（考証→実装仕様）

縮尺方針: 既存の寝殿造マップと同等のプレイ感を保つため、**郭内（堀の内側）を約70×70ユニット**、堀・馬場・田畑を含む全体を約110×100ユニットとする（実物の方形館一辺50〜100mにほぼ実寸対応）。

### 2.1 防御・境界（このマップの「顔」。寝殿造との最大の違い）

| 要素 | 考証 | 実装仕様（再利用元） |
|---|---|---|
| **堀** | 方形館の外周。水堀または空堀 | 郭外周±38〜42に幅4の帯状水面。既存の池・遣水の水面表現を流用。水を張らない北辺のみ空堀（乾いた溝＋草）にして両方見せる |
| **土塁** | 堀の内側に掻き上げた土手 | 高さ1.2〜1.5の台形断面の盛土（土色マテリアル）。上に板塀を載せる |
| **板塀・柵** | 築地（土壁）ではなく**板塀**が武家の標準 | 既存の築地生成を流用し、材質を白壁→横板張り（木目）に差し替え。高さは築地より低め |
| **矢倉門（櫓門）** | 正門。門上に矢倉を組み矢を備える（男衾三郎絵詞「矢倉をかき」） | 南辺中央。既存の門（四脚門等）の骨組を流用し、上部に板壁の矢倉層＋矢狭間を追加 |
| **物見矢倉** | 隅の見張り台 | 南東隅に単独の櫓（柱4本＋高床＋板屋根＋梯子）。新規だが柱・床・屋根ヘルパーの組合せで可 |
| **裏木戸** | 通用口 | 北辺に簡素な片開き板戸 |

### 2.2 主要建物（寝殿造の簡略形であることを見せる）

| 要素 | 考証 | 実装仕様（再利用元） |
|---|---|---|
| **主殿** | 対屋を省き一棟に機能集約（寝殿の簡略形。のちの主殿造の祖形）。屋根は檜皮でなく**板葺き**（石置き板葺き含む）。建具は蔀に代わり**舞良戸・遣戸・明障子**が増える。**置き畳**（部屋全面でなく座る場所だけ敷く） | 郭中央やや北(0,-5)。既存の寝殿（母屋＋南廂＋簀子）生成を流用し、①屋根材質を板葺きの色/質感に ②柱間を1間分縮小 ③蔀の一部を舞良戸（横桟の引戸）に差替え ④内部に置き畳2〜3枚と囲炉裏 |
| **遠侍・侍所** | 家人（郎党）の詰所。門の内側すぐ | 門の北西(-15,22)。廂なしの小型板葺き棟。既存の建物生成の最小構成 |
| **厩（うまや）** | **武士の魂＝馬**。主殿のすぐ近く、客の目に付く位置に置かれる（一遍聖絵は中門廊の先）。馬を3頭ほど繋ぐ | 主殿の東(18,0)。三間の吹き放ち＋横木（繋ぎ）＋板屋根。**馬3頭**を配置（§4） |
| **持仏堂** | 阿弥陀仏を祀る小堂。鎌倉新仏教（念仏）の時代相 | 北西(-20,-18)。方一間の小堂＋宝形風の板屋根。内部に金色の小仏 |
| **倉（板倉）** | 年貢米・武具の収蔵。高床の板倉/校倉 | 北東(18,-20)。高床＋校倉風の井桁壁＋妻入り屋根 |
| **台所（竈屋）** | 土間に竈。主殿と別棟または北に接続 | 主殿の北(0,-16)。土間色の床＋竈（既存の火・煙表現を流用） |
| **井戸** | 釣瓶井戸 | 台所脇(6,-16)。井桁＋屋根＋桶 |
| **湯屋・厠** | 別棟の習い | 北辺際に小屋2棟（外観のみ） |

### 2.3 武芸の場（武士の館たる所以。遊びの核）

| 要素 | 考証 | 実装仕様 |
|---|---|---|
| **的場（まとば）** | 郭内で日常の弓稽古。的の背後に**垜（あずち）**＝土盛り | 郭内南東(20,18)。丸的＋あずち（土色の盛土）。**既存の「破魔の矢」射撃システムを流用すれば、そのまま弓稽古ミニゲームになる（Phase 2）** |
| **馬場＋笠懸の的** | 騎射（笠懸・流鏑馬）の稽古は郭外の直線馬場 | 郭外南側、東西に長い帯(幅8×長さ60)。柵＋笠懸の的（吊るした革笠風の板） |
| **犬追物・巻狩（言及のみ）** | 大掛かりな騎射稽古 | 実装せず。的場の解説札で言及するに留める |

### 2.4 周辺（在地領主であること）

- **田畑**: 郭外の西〜北に水田区画（畦＋水面または稲色の面）。武士＝農地経営者であることを景観で示す。
- **下人の小屋**: 田の際に藁葺き小屋1〜2棟。
- **鶏**: 庭に数羽（既存の鳥系表現があれば流用、なければ省略可）。

## 3. 寝殿造マップとの対照（教材の芯）

マップ切替そのものを教材にする。ゲーム内解説・図鑑（Phase 2）はこの対比を軸に書く。

| 観点 | 寝殿造（平安・貴族） | 武家の館（鎌倉・武士） |
|---|---|---|
| 境界 | 築地塀（土壁・権威の白） | **堀・土塁・板塀**（防御の実用） |
| 中心建物 | 寝殿＋対屋＋渡殿の複合 | **主殿一棟**に集約（簡略化） |
| 屋根 | 檜皮葺き | **板葺き**（質素・実用） |
| 建具 | 蔀・御簾・几帳 | **舞良戸・遣戸・明障子**が増える |
| 床 | 板敷＋置き畳（貴人のみ） | 板敷＋置き畳（同じ系譜だがより簡素） |
| 庭 | 池泉・遣水・前栽（観賞） | **的場・馬場・厩**（鍛錬） |
| 権威の象徴 | 儀式・歌合・薫物 | **馬と弓矢**（「弓馬の道」） |
| 信仰 | 陰陽道・御霊会・加持 | **念仏・持仏堂**（鎌倉新仏教） |
| 対応する文学 | 源氏物語・枕草子 | **平家物語・方丈記・徒然草** |

> 学習到達目標: 「武家屋敷は寝殿造と"別物"ではなく、**同じ系譜の簡略化＋武の実用**である」ことを、歩いて体感した上で自分の言葉で説明できる。

## 4. 人物・動物（既存資産の流用）

- **馬3頭**（厩2＋馬場1）: 新規モデル最優先。胴・首・脚・鬣を既存プリミティブ手法で。牛車の牛の骨格実装が参考になる。
- **武士（あるじ）**: makeHeianFigure の衣装バリエーションで**直垂＋折烏帽子**（色: 藍・柿渋）。狩衣より簡素な筒袖感を色と形で表現。
- **郎党2名**: 侍所前・的場に配置（小具足なし、直垂）。
- **女房（妻）**: 袿姿を簡素化（小袖袴風の色数減）。主殿内。
- 既存の平安人物・怪異・和歌短冊は**このマップには出さない**（時代混濁を避ける。将来「鎌倉の怪異」「平家の亡霊」は §7 で別途設計）。

## 5. 実装アーキテクチャ（Opus委譲仕様の骨子）

1. **起動切替**: `?map=kamakura` のURLクエリ（`APP.map` に保持、既定は `"shinden"`）。既定マップは1バイトも挙動を変えない＝回帰ゼロを最優先。
2. **コード配置**: 新規ブロック `src/app/map-kamakura.js` を **APP_KAMAKURA_EMBED** マーカーで本体HTMLへ同梱（`scripts/app-manifest.json` に1エントリ追加＝確立済みの手順）。ブロック内は「データ（配置表）＋ビルダー関数」。既存ヘルパー（屋根・柱・床・塀・水面・木）を呼ぶ。
3. **フック**: ワールド構築の入口で `APP.map === "kamakura"` なら `buildKamakuraWorld()` へ分岐（1箇所・数行の本体パッチに限定。html-scout の調査結果に従う）。
4. **共用システム**: 季節・時刻・天候・画質・移動・衝突・ミニマップは共通機構に載せる（マップ固有の当たり判定と minimap 形状のみ登録し直す）。
5. **図鑑・クイズ**: Phase 1 では未登録（名称札の最小表示のみ可）。Phase 2 で ITEMS に「武家」カテゴリを追加し、クイズ鎌倉編を作る。
6. **検証**: 既定マップの `npm test`（smoke 含む）が無変更で緑のこと。`?map=kamakura` の起動スモークを `scripts/smoke-playwright.js` に1シナリオ追加（QA_STRATEGY.md の方式）。

## 7. 平家物語再現ロードマップ（将来）

| 段階 | 内容 | 再利用 |
|---|---|---|
| Step 1 | **本マップ**＝東国武士の館（坂東武者の生活空間。宇治川先陣・熊谷直実らの「出自」の風景） | 寝殿造エンジン全般 |
| Step 2 | **都サイド**＝六波羅・平家一門の邸は、**既存の寝殿造マップをそのまま再利用**（調度・人物・雰囲気の差し替えのみ。平家は貴族化した武家なので考証的にも正しい） | 寝殿造マップ丸ごと |
| Step 3 | **語りモード**＝琵琶法師の「語り」を軸に、祇園精舎・敦盛最期・壇ノ浦などを章立て。**物語エンジン（dialogue/choice/stage/現雅蝕の器）と「巡り歌合」で作るイベント基盤をそのまま流用**。冒頭「祇園精舎の鐘の声」は暗唱教材の定番＝音読・暗唱ミニゲームの好機 | story_runtime 一式 |
| Step 4 | 合戦景観（一ノ谷の逆落とし＝崖地形、壇ノ浦＝海と船） | 新規地形。最後に判断 |

> 教材接続: 平家物語は「軍記でありながら、歌と無常観の文学」。§3 の対比表と「巡り歌合」の和歌基盤（waka-notes）が、そのまま「忠度都落ち（歌人としての平家）」「敦盛の笛」等の情緒パートを支える。**武と雅の二重性**——この作品群全体を貫く軸になる。
