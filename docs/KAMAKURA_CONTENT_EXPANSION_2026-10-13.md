# 鎌倉の館：荷・書付・配膳の追加

2026-10-13調査開始、10-14実装。基準は13世紀前半。特定の武家屋敷の復元ではなく、生活の仕事を見て回る学習模型。既存の主殿・侍所・倉・竈屋・厩・湯屋・厠・田・矢場を複製せず、荷受けの庇、書付の小部屋、配膳の庇という三つの仕事場を加えた。

## 実装した内容

| 場面 | 位置 (x,z)・床高 | 造形・仕事 | 新しい図鑑ID |
| --- | --- | --- | --- |
| 荷受け | (24,-10)・地面 | 柱・桁・北の板壁・板屋根。脚で支えた台に開口と底のある曲物、縄で結ぶ包みと付札。包みを両手で抱える人 | niuke / magemono / nifuda / nihakobi_k |
| 書付 | (-15,-6)・0.36m | 三段の階段、床、北壁、開放した正面。低い机に紙・墨・硯・口のある水滴。筆を持つ座位の人物と、正面脇で書状を持つ使者 | suzuri_k / shojo_k / kakite_k / tsukai_k |
| 配膳 | (-7,-19)・地面 | 竈屋の西北。脚と貫で支える台、内側をくぼませた漆椀、箸、曲物。盆と椀を両手で支える人物 | haizendai / urushiwan / hashi_k / haizen_k |

12図鑑項目、4役、3仕事場。人物の担当名はゲーム内の説明名で、史実の固定役職名や一律の身分区分ではない。衣の色も創作。直垂の書付役・使者は上下で同じ布materialを使い、作業着の二人へ直垂の条件を強制しない。

図鑑は全12項目に既存register/rayTargets/名称札を接続。子の道具を先に登録し、庇の親登録が道具のIDを塗り替えない。書付役を調べると仕事内容と、統合済みの場合は「書付を照合する」の選択が出る。新しい文書ゲームの内容・採点・保存は別モジュール `kamakura-customs.js` の担当。

## 接合・資源・歩行

- 新しい矩形部材は単位BoxGeometryを共有。曲物・椀は底と内壁を含む共有LatheGeometry。服の同じ輪断面もキャッシュして人物間で共有する。大きな新texture・光源・毎フレーム走査は追加しない。
- 支柱は地面から梁へ、梁は屋根底へ接続。机の4脚は天板下へ重なり、二本の貫がそれぞれ二脚に接する。曲物・椀・硯・紙は台の上面を基準に置く。
- 書付役は既存の立脚を除き、同じ布の膝へ座位の上半身を接続。筆は右掌から紙まで伸ばす。運搬役の包み・使者の紙・配膳役の盆は掌に重なり、盆の上面に椀の底を接地。
- 座位への変換は名前を付けた足首・足・立位の袴だけを除去する。原点に置く烏帽子グループは残し、頭と同じ0.46mだけ下げる。無名部品の原点を足の判定に使わない。
- 新しい柱、北壁、作業台、床上の包みに歩行衝突を追加。矩形には既存の歩行者半径0.22mを含める。書付の床と三段の階段は造形寸法と同時にKAMA_ZONESへ登録。floorZonesを上書きしない。
- 門・主殿・持仏堂の既存動線、x=20・z=18〜25の射線、外の馬場は維持。荷受けへは西脇を回り南から入る。北壁を横断する経路にはしない。
- 荷受けの軒に幹が通らないよう、既存の松1本を(27,-9)から(29,-9)へ移動。木の造形・植栽数は変えていない。
- 既存の図鑑ID、セーブキー、時代比較、walk/title/quizの許可範囲は維持。新模型部分はセーブを直接読み書きしない。

## 公開APIと統合点

`window.KAMAKURA_WORLD = {K, world:worldK, anchors, contentIds}` をmap末尾で公開。平安側では作られない。init時点で図鑑と既存K.modal/K.pickHook/K.frameHookが完成している。別モジュールは既存hookへ委譲して重ねる。

`K.kyudoStart() / K.kyudoShoot(sx?,sy?) / K.kyudoStop(silent?)` も公開。引数なしの射撃は画面中央。開始時は一人称と射座へカメラを同期し、停止/結果時は開始前のviewへ戻す。start/stopで世代を進め、飛翔後の着弾と650ms後の結果を、同世代・active・walk・可視worldで検査する。退出時は結果timerと刺さった矢を掃除する。草庵active中はmapのanimate後処理も実行しない。新ゲームの開始前はstopを呼び、互いの操作を重ねない。

## 検証と目視

`scripts/kamakura-content-playwright.cjs` は12項目の図鑑/クリック登録、柱・梁・机脚・貫の接合、共有geometry、机上の器、筆と紙、手持ち道具、座位と布素材、4接近点、歩行3経路、床段差、旧弓稽古の中断/再開/古い着弾/古い結果/退出、図鑑表示と書付会話を検査する。飛翔のcallback差し替えはテストのpage.evaluate内だけで、製品にdebug globalは追加しない。

既存 `scripts/kamakura-refinement-playwright.cjs` の直垂検査は、座った袴にも同じ素材一致を要求するよう拡張。既存の立位を検査対象から外していない。

最終QA追補：書付役の烏帽子が人物の子に残り、頭部へ接することを検査する。また鎌倉で実際のcore animateを夜・昼それぞれ12回通し、平安側の鬼・式神・晴明・妖怪・四神・童/雀が再表示されないことを確かめる。開始前に対象だけを一度visible=trueへするため、初期非表示のまま偶然通る検査にはしない。四神の発見済み状態が変わらないこと、LIVING_ESTATEの3種の来客APIが拒否され、来客がsceneに増えないこと、鎌倉の図鑑モデルが可視のままであることも検査。coreの夜間量・四神・童のmap条件は統合担当、LIVING_ESTATE.walkModeのmap条件は本担当の修正。scene全体を毎フレーム隠す方法は使わない。

2026-10-14時点：担当側は4ファイルの `node --check` と `git diff --check` を通過。生成HTMLのbuild・ブラウザ実行・スクリーンショット判定は統合担当が行うため、ここでは合格済みと記さない。
