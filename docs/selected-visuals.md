# 人物・天候の追加演出（#101–104、#106–109）

`src/app/heian-expression.js` の人物リグと `src/app/selected-visuals.js` の更新処理を使う。後者は人物・水鳥・天候が生成された後に読み込み、既存の水鳥と表情更新より後で `SELECTED_VISUALS.update(dt,t)` を呼ぶ。

| 番号 | 実装と観察点 |
|---|---|
| 101 | 扇・巻物・笏を手と同じ支点へ移し、所作で手と持物が離れないようにした。座位の笏は既存生成処理で親に追加されていなかったため、リグ側で補う。 |
| 102 | 巻物は目線を下げて両手を低く、扇は顔の方へ緩く上げ下げし、笏は小さく安定して保持する。低動作設定では周期動作を止める。 |
| 103 | 布の末端が床を抜ける場合は支点を小さく持ち上げる。後ろ裾を役割に応じて伸縮し、体との重なりや床との交差を減らした。 |
| 104 | NPC の会話表示中は、その ID に登録された人物だけがプレイヤー側へ身体を最大約35度向け、会話が終わると会話開始時の方角へ戻る。通常の巡回方向は上書きしない。 |
| 106 | 既存の屋内床判定を軒下判定にも用い、雨にさらされる時だけ画面の滴と人物の布色・粗さに濡れを加える。軒下に入るとゆっくり乾く。 |
| 107 | 池面 `y=.06` に鴛鴦の胴体下部と鯉の上面を合わせ、鴛鴦の足元に広がる波紋を足した。鯉の既存波紋も水面へ合わせる。 |
| 108 | 積雪時に庭を歩いた位置へ交互の足跡を残す。16枚を再利用し、約6.5秒で消す。屋内・池・省電力モードでは生成しない。 |
| 109 | 主役の人物は長めの後ろ裾、取り次ぎ役は短めの裾、笏を持つ人物は既存の冠・袴を維持する。役割をゲーム上で読み分けるための解釈であり、人物の実在の時代や身分を衣装だけで断定しない。 |

## 造形の参照範囲

一次史料は徳川美術館所蔵の12世紀の[『源氏物語絵巻』](https://www.tokugawa-art-museum.jp/collections/%E6%BA%90%E6%B0%8F%E7%89%A9%E8%AA%9E%E7%B5%B5%E5%B7%BB/)と、その[修理報告に掲載された現物図版](https://www.tokugawa-art-museum.jp/wp-content/uploads/2025/02/42_0-%E9%87%91%E9%AF%B1%E5%8F%A2%E6%9B%B842.pdf)。重なりのある襟・袖と裾の輪郭を形の参照に留めた。色、役割ごとの裾の長短、個々の小物は本ゲームの視認性に合わせた造形であり、絵巻から階級ごとの厳密な服制を復元したものではない。京都国立博物館の[絵巻展示解説](https://www.kyohaku.go.jp/old/jp/theme/floor2_1/f2_1_koremade/emaki_20170221.html)も、重ねた衣と長い髪が画面でどう描かれるかの確認に用いた。

## 確認

`node scripts/selected-visuals-playwright.js` で手持ちの親子関係、行動別の姿勢、頭傾きの非蓄積、会話後の復元と通常巡回への非干渉、池面との高さ、雨宿りと布材質の濡れ、雪足跡の寿命、省電力時の非表示、固定数の再利用を確認する。近景と中景は `artifacts/review/selected-visuals-near.png` および `artifacts/review/selected-visuals-mid.png` に保存する。ブラウザの WebGL 例外も検出する。
