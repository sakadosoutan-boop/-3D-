# 鎌倉・弓稽古と笠懸

正本は `src/app/kamakura-games.js`。`src/app/map-kamakura.js` が作成した `window.KAMAKURA_WORLD` を受け取り、最後の初期化位置で `KAMAKURA_GAMES.init(window.KAMAKURA_WORLD)` を一度呼ぶ。毎フレームの `KAMAKURA_GAMES.update(dt,t)` は、core のカメラ補間後、描画前に呼ぶ。馬・弓・照準の位置はこの順序に依存する。

## 弓稽古の問題と修正

従来の canvas 操作は、押してから 450 ms 以内、視点移動 14 px 未満のタップだけを `pick()` に渡した。弓を狙いながら押すと射撃されず、「矢が射てない」と感じる。短いタップと視点ドラッグは従来どおり残し、常時見える「射る」ボタンから既存の `K.kyudoShoot(x,y)` を呼ぶ。視点を動かした後でも画面中央へ確実に撃てる。射座開始時のカメラ・標的 world matrix 同期、射撃・着弾・終了の世代管理、モード退出時の後始末は map 側の `K.kyudoStart/Shoot/Stop` が担当する。

元の矢立ては装飾だけでクリック対象ではなかった。新しい矢立て目印を (22,20) に重ね、近づいた時のボタンと 3D pick の両方から新たな10射を始める。補充は進行中の稽古を世代ごと止めてから新しい回を開始し、自己ベストは既存の記録を使う。

## 笠懸の遊び

馬場入口に開始目印と近接ボタンを置いた。馬上視点で往路3射、折り返して復路3射を行う。復路の的は既存の的メッシュを低く、小さく配置し、退出時に位置・scale を復元する。押し続けると弓弦と番えた矢が引かれ、離した時の画面位置から対象の実メッシュへ raycast する。中心2点、その他の的中1点。音と得点は矢が着いた時に出す。時間窓を過ぎれば失中。練習は低速、本番は高速で、照準補助は明示的に切り替える。既存の四脚だけを pivot へまとめて歩様を付け、蹄音を小さく鳴らす。馬の元位置・回転・可視性、的の位置・大きさ、プレイヤー視点、カメラ、UI を退出時に戻す。草庵訪問やモード変更でも停止する。

画面用の弓は、既存人物の弓と同様に下を短く上を長くし、低い縦握りを置いた。引き絞り中も弦の中央と矢筈を同じ点で動かす。[全日本弓道連盟の現代用具説明](https://www.kyudo.jp/begin/tool.html)が示す握り位置を形の参考にしたもので、鎌倉期の用具寸法を規定する記述ではない。

騎乗中は `body.kasagake-active` で散策用の時間・季節表示、移動スティック、「調べる」、通常トーストを隠し、上部は一時停止・図鑑・設定などの操作を残す。命中表示は専用 HUD に出す。終了時に class を外して散策 UI を戻す。

実際の笠懸は流鏑馬の一方向・三的と異なり、馬場を往復する。遠笠懸と小笠懸では的の距離と大きさが異なる。このゲームは既存の約60 m馬場と三つの的を用いた短縮体験で、史料の寸法や的数をそのまま再現したものではない。[古殿町教育委員会「笠懸と流鏑馬の作法」](https://www.town.furudono.fukushima.jp/kanko-dentou-bunka/see/bunnkazai/hatimannjinnjya/kasagakerekisi/sahou/175)、[大日本弓馬会「上賀茂神社笠懸神事のみどころ」](https://yabusame.or.jp/wp/wp-content/uploads/2022/09/kamigamo-kasagake_2022.pdf)。

## 検証

`node scripts/kamakura-games-playwright.cjs` は `npm run build:app` 後に実行する。実際の canvas mouse/touch 入力から射数・的中を確認し、補充、馬上6射、折返し、score、退出時の復元、モード変更時の停止を検査する。昼・復路・スマホ・夜の画面画像も保存し、夜は core の `animate()` で実際の光源値を更新してから撮る。親の統合担当がブラウザ実行順を管理する。
