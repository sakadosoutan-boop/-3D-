# 杜若・蓮・撫子の形状改善 — 2026-09-15

この表は水面の貼り方・重なりの追加修正前に、草花の変更分を測った記録。最終版の確認は [水面を含む最終記録](GARDEN_FINAL_2026-09-15.md) を参照。

比較基準は `4624720`。今回は花・葉を細かくしながら、株ごとに描画をまとめて負荷を抑えた。

## 改善内容

- 杜若：四角い葉を、折れ目と先細りのある曲面へ変更。外側に垂れる3枚の花弁には淡い筋を入れ、内側の3枚を立ち上げた。花の下に茎を通し、浮いて見える部分をなくした。
- 蓮：平らな多角形の葉を、緩く反る48分割の葉へ変更。葉脈に沿う淡い色差を付けた。花は円錐6個から、外8枚・内6枚の曲がった花弁、中心部、茎の構成へ変更した。
- 撫子：正面向きに重なっていた平板を、上向きに開く5枚の花弁へ変更。縁の切れ込みと中心から外への色差を付け、細い葉を茎に添えた。
- 曲面形状・材質を共有し、花弁・葉・茎を株ごとのInstancedMeshにまとめた。小さな草花自身は影を落とさず、周囲の影を受ける。画像・ライト・影マップ・後処理は増やしていない。
- 花の色と陰影は頂点カラーで表現する。追加のアニメーションや毎フレーム処理はなく、省電力でも同じ形状を使える。

季節による表示と、杜若・撫子を調べるための登録は維持した。r128のインスタンス描画に合わせ、株の全形状を覆う保守的な境界球を使い、画面外の株を省略する。境界球がすべての配置済み頂点を含むことを自動検証した。

## 性能比較

Chrome headless、1280×800。高画質はDPR 1・影1024・既存IBL・法線マップ・AOあり。低消費電力はDPR 0.56・影/IBL/法線マップ/AOなし。自動画質・ブルームを停止し、各版を固定乱数・時刻・視点で測定した。

オブジェクトの生成数が変わるため、乱数シードを同じにしても、花の高さ・葉の大きさ・開花数などには版間差が含まれる。株を置く固定座標は共通。完全に同一の花の配置だけで比較した値ではない。

毎回Chromeを起動し直し、同時に開くゲームを1個に限定。「前→後→後→前→前→後」で各3回測定。各場面32回描画し、最初の8回を捨てて24回の中央値を取り、表は各版3回の中央値。画像保存は性能計測から分離した。
