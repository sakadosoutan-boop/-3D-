# 軒下・橋・藤棚・竹林の改善 — 2026-09-20

基準は `2d88b84`。専用ブランチ `codex/astra-quality-review` で実装。

## 変更

1. 主要建物の軒下に垂木を追加。約56cm間隔で、各材を二分して屋根の反りへ追従する。屋根ごとに1描画へ統合し、追加の投影影は無効。低画質・省電力では非表示にし、復帰時も同じ形状を再利用する。
2. 寝殿上部の白壁に細い木枠を追加。枠全体を1つのメッシュにまとめる。
3. 太鼓橋3本の擬宝珠を曲線のある形へ変更。床板・桁・束・高欄を既存の3材質ごとに統合。477部品を9メッシュにし、曲面・床高さ・庭園のクリック判定を維持する。
4. 藤の丸い花粒を蝶形の花へ変更。480輪を1回で描き、房の先ほど小さく淡くする。花軸と棚へ伸びる蔓を追加。
5. 藤の葉を、対生する小葉3対と頂葉が枝から伸びる形へ変更。花・花軸・葉・葉柄・棚は各1描画。春夏の開花条件を維持。
6. 竹の四角い葉を、尖った先端と中央の折れ目を持つ葉へ変更。節から短い枝を伸ばし、葉の根元をつなぐ。枝は幹と同じ描画へ統合し、材質は竹林全体で共有する。
7. 追加したInstancedMeshは全配置を包む境界を初期化時に算出。元形状の境界も含め、Three r128のカリングとインスタンスごとのクリック判定の両方を保つ。

新しい画像・光源・毎フレーム更新は追加していない。藤・橋の描画回数は減る一方、垂木や竹の枝・葉の頂点数は増える。

## 確認

最後にまとめてテストを実施。初回のスモークで、藤棚の旧コードが座標の数値を1要素配列として渡していた問題が描画統合によって顕在化したため、数値へ修正。成功済みの静的チェックは繰り返さず、失敗したスモークと後続の確認を実施した。

埋め込み同期・HTML・物語・ルート整合、PC/モバイル相当のスモーク、品質回帰7件、描画回帰12件が成功。追加回帰では、全インスタンスの境界、藤の花弁と橋のraycast、開花条件、省電力での垂木の非表示と復帰を確認。季節・省電力の繰り返し切り替えでリソースを再利用することも確認。JavaScript・シェーダーエラー0件。
