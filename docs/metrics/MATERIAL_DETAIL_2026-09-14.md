# 石・木材・縁側の近景改善 — 2026-09-14

比較基準は `03a311a`。前回の水面・接地影・樹木の立体感を維持し、今回は素材の描き方と貼り方を改善した。

## 改善内容

- 柱の木目が横向きの輪になっていたため、角柱・丸柱とも部材の長手方向に沿う貼り方に変更。横梁は長い方向に木目が通る。
- 板敷きは板幅が約28cmになるよう実寸に基づくUVへ変更。大きな床でも小さな床でも、板目が同じ太さになる。
- 簀子の板幅を約26cmに整え、幅広い黒帯だった隙間を細くした。20枚の板を画像の上下端まで均等に割り付け、板ごとの色差も弱めた。
- 床の木目を緩やかな曲線にし、画像の左右端で同じ高さに接続するようにした。
- 飛び石・汀石から規則的な横筋を除き、小さな鉱物粒、淡い鉱物の筋、柔らかい色むらに変更。色むらは上下左右へ描き継ぎ、タイル境界が目立たないようにした。
- 樹皮の太く強い溝を細く穏やかにし、幹の周方向の模様を細かくした。

画像の枚数・解像度、ライト、ポリゴン、シェーダーの処理は追加していない。UVの変換は形状の生成時に行い、共有キャッシュで再利用する。毎フレームの処理追加はない。

UVの異なる木材・床材・その他の素材は別のキャッシュキーにし、同じ寸法の壁や調度品へ木目の貼り方が混入するのを防いだ。AO用UVも色テクスチャと揃えている。追加の色むらには専用の固定乱数を使い、既存の乱数呼び出しの順序・回数を維持した。
