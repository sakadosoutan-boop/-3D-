# 樹木の枝・根元・葉の改善 — 2026-09-18

比較基準：`5dc41d1`。実装後に全体テスト1回、前後比較各1回をまとめて実施。

## 実装

- 広葉樹の8個の葉叢に、それぞれ幹から折れながら届く枝を追加。枝先に向かって太さを絞った。
- 幹の根元に5方向の根張りを追加。先端を地中へ収め、地面とのつながりを作った。
- 幹・枝・根を一つのBufferGeometryへ結合。既存の幹メッシュと樹皮材質を使い、木1本あたりの描画回数を増やさない構成とした。
- 既存128×128の葉画像を細い葉形と葉脈に描き替え、薄い大きな斑点から細かな重なりに変更。中立色のまま季節の着色を維持する。
- 新しい画像・材質・ライト・後処理・毎フレーム処理は追加していない。追加した形状は季節切替で再利用する。
