# 庭・水面・空の描画品質向上 — 2026-09-14

前回の質感改善 `f9f9d9a` が比較基準。ユーザーの「多少だけは重くなってもいい」という方針を受け、小さな追加負荷で輪郭・陰影・水面の動きを改善した。

## 実装

- 樹木・植え込みの葉群を共有する12×8の球面形状に変更。周期補間した輪郭で継ぎ目の割れを防ぎ、上から下への頂点色の陰影と細かな葉模様を加えた。松の頂芽にも中立の頂点色を設定し、黒くなる問題を防いだ。
- 浮いて見えた低木を地面に埋め、回転を穏やかにした。桜・梅にも既存の葉模様を使用。
- 飛び石11個に薄い厚みと不均一な輪郭を追加。メッシュ・材質の個数は維持。
- 水面の既存シェーダー内で3方向の波を合成して法線を変化させる。青緑の色と反射の強さを調整。新しい反射用描画パスは追加していない。
- 既存の雲ドーム内で空の上下の色を補間し、夜の雲の明るさを抑えた。
- 木・植え込み・建物の下に柔らかい接地影を追加。128×128の画像2枚を起動時に生成し、3個のInstancedMeshにまとめる。リアルタイムAOではなく、地面に固定した薄い影。
- 低画質または低消費電力では追加の水面波と接地影を停止し、葉群を従来程度の分割数へ戻す。簡易形状は初回切替で生成し、その後は再利用する。追加の照明・影マップ・後処理パスはない。

## 描画時間

Chrome headless、1280×800、固定乱数・視点・時刻。高画質はDPR 1、影1024、法線マップ・AO・既存の環境反射（IBL）あり。低消費電力はDPR 0.56、影・法線マップ・AO・IBLなし。自動画質・ブルームは両版とも停止。

前回記録では自動操作環境としてIBLが無効だったが、今回は高画質を通常の非タッチPCに合わせてIBL有効で比較した。前回の絶対時間との直接比較には使わない。

各回Chromeを起動し直し、同時に動くゲームを1個に限定。実行順は「前→後→後→前→前→後」。各場面32回描画、最初の8回を捨てて24回の中央値を記録し、表は各版3回の中央値。計測時は画像保存を停止した。
