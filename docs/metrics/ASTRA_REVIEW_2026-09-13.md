# Astra 品質レビュー — 2026-09-13

対象は `origin/main` の `44986bf`。改修ブランチは `codex/astra-quality-review`。
作業フォルダ直下と `-3D-` のHTMLは公開元より古かったため、最新コードから独立した作業場所を作成した。既存の未コミット変更は維持している。

## 評価

寝殿造りの探索を核に、古語・和歌・物語・遊戯へつながる題材の広さが強み。一方、機能を増やした結果、入口に並ぶ情報の密度とモード間の進行管理が弱点になっていた。今回は新モードの追加より、読みやすさと再開始・一時停止の確実性を優先した。

## 修正した問題

| 優先度 | 確認した問題 | 改修後 |
|---|---|---|
| 高 | 一日体験の対象を連打すると、予約処理が重なって手順を飛ばす | 同じ手順の受理は一度だけ。対象の手順とセッションが一致する場合だけ進む |
| 高 | 正解直後に新しいクイズを始めると、古い最終問題の処理が新しいクイズを終了させ得る | 待機処理を現在のモード・セッションに紐付け、離脱時に破棄 |
| 高 | 一時停止中もクイズの正解待ち・一日体験の自動進行や会話が進む | これらの待ち時間をゲームの更新に統合して停止・再開 |
| 中 | 一時停止から復帰すると、アニメーション時計に停止時間が加算される | 経過時間を保ったまま、再開時の時計の基準を更新 |
| 中 | ヘルプ背後の移動、入力欄への打鍵、タッチ中断がゲーム操作に影響 | 操作を受け付ける画面を判定。タッチ中断と一時停止で入力を解除 |
| 中 | 再度開いた解説が2.2秒で消え、読み返しにくい | 解説を閉じるまで保持。閉じるボタンの配置と読み上げ名も修正 |
| 中 | 表紙の5カテゴリがPCで4＋1に分かれ、説明文が小さく低コントラスト | PCは5列。900px以下は散策を大きく先頭に置き、残り4カテゴリを2列で配置。文字を読みやすく調整 |
| 中 | WindowsのCRLFチェックアウトで `build:app:check` がマーカーエラーになる | `.gitattributes` でHTML・JS・CSS・JSONの改行をLFに統一 |

- 追加の7シナリオ：一日体験3連打、クイズ最終問題直後の再開始、クイズと時計の一時停止、一日体験の自動進行停止と離脱、古い一日体験の処理の遮断、ヘルプ／文字入力／タッチ中断、解説再読と手動終了。

## 残る改善候補と検証範囲

- 散策開始地点の1フレームで約1,700 draw calls、約22.6万三角形。シーンのランダム生成や視点でも変わるため、性能改善の前後比較には用いていない。低性能端末では静的な小物の描画統合を、見た目と選択判定を維持しながら検討する余地がある。
- 今回の停止処理の修正対象はクイズ・一日体験の予約進行と共通アニメーション時計。ほかのミニゲームにある独自タイマーすべてを同じ方式へ移行したわけではない。
- 既存スモークのオンライン検査はテスト用構成。実際の2端末接続・本番サーバーとの対戦や協力は未検証。
- 物語は既存のデータ・ルート検査を実施。全文の校閲や全プレイルートの手動通読は今回の対象外。
- ローカル改修を完了。公開サイトへの反映は行っていない。
