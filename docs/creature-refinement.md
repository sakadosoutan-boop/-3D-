# 人物・生き物・怪異の近景造形

`heian-expression.js` は座位・立位で共用する頭部の表面を一度だけ調整し、頬から顎への立体感を連続した面にする。先に加えていた別々の頬・顎の球は使わない。首は頭と襟の内側へ差し込む細いテーパー、短い側髪は前髪から既存の長い側髪へ続く共有形状にした。会話中の頭の向きと目線支点、既存の顔・袖・重ね襟・持物は保持する。部品は既存の肌・髪材で結合し、人物ごとに重いSDFを生成しない。

`creature-refinement.js` は世界生成後に `CREATURE_REFINEMENT.applyWorld()` を一度呼び、描画更新から `CREATURE_REFINEMENT.update(camera)` を呼ぶ。鴛鴦・鶴の嘴は頭へ差し込む連続した細い管形、翼は胴から羽先まで一枚の波形面にした。両方とも役者間で形状を共有する。牛は既存の暗い毛・淡い鼻・黒い蹄と色/粗さを揃え、額・口元・耳内側・割れた蹄を接続する。蹄は既存の脚支点の子で、動く脚を静止形状に結合しない。鯉は平面画像に目・鰭・尾が描かれ、接水のshaderもその平面を使うため、重複する立体鰭を足さない。

環境怪異は河童の耳と鼻孔、提灯の紙骨と舌につながる口、雪女の袖先の手、人魂と狐火の炎先端を補う。鬼は既に角・牙・頬・顎・爪・金棒まで持つため重複造形を加えない。戦闘ボスのGLBと予兆は維持する。既存の親root・ray対象・当たり判定には手を加えない。

造形追加は一度だけ適用される。各役者の静止した同材質の小部品を結合し、共有元geometryを破棄しない。近景詳細は13m以内で表示、17m以遠で非表示。省電力時は9m/12mへ縮める。人魂・狐火の炎先端は遠景の輪郭として残す。`node scripts/creature-refinement-playwright.js` は統合後の世界で二重適用が無いこと、牛の蹄が脚支点に追従すること、近景LOD、ray対象数が変わらないことを確認する。近景・中景の絵のつながりはブラウザで別途確認する。

参考にした第七段の `tsurezure-figures.js` は、肌・髪・衣の粗さを分け、顔と衣の形を連続面にしている。`tsurezure-nature.js` の烏は嘴と羽の輪郭を一体で作り、形状を共有している。本実装はその形状・材質・共有の考え方を軽い既存役者向けに移した。第七段のSDFや表現用ソースは変更していない。戦闘GLBは各1メッシュ/1材質で顔や装具の個別支点が無いため、浮く危険のある追加部品は付けない。

2026-10-13、統合後の専用ブラウザ検査とnpm testが合格。鬢の外向き法線、既存河童の肩/腕/手と提灯の口/舌の接合、蹄の動作/戻り、近景LOD、二重適用なし、ray対象数の保持を確認した。画像では鴛鴦・鶴・牛・河童・提灯・雪女の近景を確認する。共用の元部品を動かす補正と追加詳細を分け、原世界の支点を維持した。
