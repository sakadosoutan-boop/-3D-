# 戦闘と雅遊びの選択改善（2026-10-08）

この変更は単一HTMLへ埋め込む `src/app/combat.js`、`utakai.js`、`kemari.js`、`kaiawase.js` の正本で実装する。補助表示は `combat-upgrade.css`。

| 番号 | プレイ中の変化 | 確認点 |
| --- | --- | --- |
| 71 | 赤は回避専用でガード不可、桃霞は弾ける。床の円・線は実際の半径・幅で塗る。突進の重複接触判定をなくした。 | 円・線の表示寸法と判定、赤と桃霞のガード結果 |
| 73 | 大鬼・巨大人魂にロックすると足元も見える高さへ視線を下げ、画角を広げる。解除・戦闘終了で元の画角に戻す。 | ロック中と解除後の画角 |
| 77 | 矢は急所への精密射で体勢を削り、札は周囲の飛び道具も祓い、太刀は夏の攻撃後の隙を斬る。共有HPへ送る基礎ダメージは従来のまま。 | 各武器の役割と結果表示 |
| 78 | 河童と提灯が交互に攻撃し、次撃まで2秒以上の間を置く。突進後の隙は移動終了後から始まる。片方を倒すと残りは単独行動へ戻る。 | 行動順、隙の時刻、単独移行 |
| 80 | 討伐した怪異の図鑑を解放し、攻撃の読み方と伝承との関係を討伐記として保存する。史実とゲーム独自の演出を区別する。 | 討伐前後の `taijiBossCodexNotes(id)` |
| 83 | 初期手札が題・場に弱い場合、一首だけ貸し札を差し込む。札はその歌合だけで使え、図鑑の収集数を増やさない。 | 貸し札表示、収集状態 |
| 84 | 歌合の初番から技法指定の特別戦を選べる。指定技法を詠むと24点、外すと8点減点。判詞の内訳に理由を残す。 | 技法札の保証、採点内訳 |
| 87 | 蹴鞠で落とした理由を、位置・時機・技の順に一つ表示する。結果画面にも次の一鞠への助言を残す。 | 失敗ごとの文言、既存得点維持 |
| 89 | 貝を揃えると絵柄の景物を既存和歌から探し、歌・作者・収集状況を表示する。終了時に覚えた景物を示す。 | 合わせた貝と和歌の対応 |

検証は親が `npm run build:app` を実行したあとに `node scripts/selected-combat-playwright.js` を実行する。戦闘の赤/桃霞と危険域寸法、夏の交互行動、画角の復元、貸し札と技法点、蹴鞠の失敗理由、貝の和歌、討伐記の保存をブラウザ上で検査する。
