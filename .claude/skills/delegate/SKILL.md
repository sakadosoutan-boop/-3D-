# delegate — サブエージェント委譲の標準手順

1. タスクを「探索（読むだけ）」と「実装（書く）」に分解する。
2. 探索は model: sonnet、実装は model: opus のサブエージェント（Agentツール）に委譲する。
   本体HTML内の調査は html-scout エージェント（.claude/agents/html-scout.md）を使う。
3. サブエージェントへの指示には必ず次を明記する:
   対象パス / 完了条件 / コミット規約 / 「push禁止・ローカルコミットのみ」。
4. 本体（オーケストレーター）は結果の検証（git diff・テスト実行）と統合のみを行う。
5. 独立したタスクは並列で走らせる。
