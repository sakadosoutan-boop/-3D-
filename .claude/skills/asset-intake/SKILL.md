# アセット取り込み

ops/ASSET_PIPELINE.md のSOPを実行する。ここには判断の要点だけ書く。

## 手順

1. **受け取り**: 対象ファイルの場所・種類（GLB/画像/音源）・用途（どのボス/どの画面/どの場面の音か）を特定する。
   用途が不明なら AskUserQuestion で確認（組み込み先を間違えると実機確認の往復が1回無駄になる）。
2. **出典確認**: 出典・権利情報を必ず聞くか推定する（Manex3D生成 / Canva design ID / 音源サイト名）。
   不明のままの公開ビルド入りは不可 — その場合は組み込みを保留してユーザーに確認。
3. **SOP実行**: ops/ASSET_PIPELINE.md の該当セクションどおりに、配置・命名・軽量化・記録（ASSET_MANIFEST.md / sounds/CREDITS.md / 埋め込みコメント）・アプリ接続まで行う。
   - GLBの軽量化設定（簡略化なし・圧縮なし・テクスチャ2048 WebP）は変えない。
   - 生データは `.asset_work/` へ。**元ファイルの削除はユーザー確認なしに行わない。**
4. **検証**: `npm run preflight`。GLBはボス戦を起動して接地・スケール・向きを確認（スモークで拾えないため、実機確認項目としてユーザーにも伝える）。
5. **コミット**: `feat: <内容>` 形式。ファイルサイズの増分（htmlBytes / リポジトリ）を報告に含める。

## 報告形式

- 取り込んだもの: （置き場所・最終サイズ・元サイズからの削減率）
- 記録した出典: （manifest / CREDITS の追記内容）
- アプリ接続点: （検索アンカー名）
- 実機で確認してほしいこと: （1〜3項目）
